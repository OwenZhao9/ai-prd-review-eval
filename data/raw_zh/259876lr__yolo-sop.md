## 1. 产品概述

### 1.1 产品背景

在制造业生产线上，标准作业程序（SOP）的严格执行对产品质量和生产安全至关重要。传统的人工监督方式存在效率低、成本高、易疏漏等问题。本产品利用最新的YOLO26深度学习技术，实现对生产线工人操作行为的实时智能检测和SOP合规性验证。

### 1.2 产品定位

面向制造业生产线的智能SOP合规检测系统，提供实时视频分析、工序识别、异常告警和数据统计功能。

### 1.3 目标用户

| 用户角色 | 描述 | 主要需求 |
|----------|------|----------|
| 生产主管 | 负责生产线管理 | 实时监控生产状态、查看合规报告、处理异常事件 |
| 质量管理员 | 负责产品质量控制 | 分析工序执行情况、追溯质量问题、优化SOP流程 |
| 系统管理员 | 负责系统运维 | 配置系统参数、管理用户权限、维护模型 |
| 一线工人 | 被监控对象 | 获得操作反馈、了解自身表现 |

### 1.4 YOLO26 + MediaPipe技术优势

本系统采用**YOLO26 + MediaPipe**联合检测架构，充分发挥两者优势：

#### YOLO26核心优势

| 特性 | 描述 | 业务价值 |
|------|------|----------|
| One-Stage, One-Box | 无需NMS后处理 | 推理速度提升30%+，降低系统延迟 |
| 边缘端优化 | 专为边缘设备设计 | 支持本地部署，降低硬件成本 |
| CPU性能提升 | 优化CPU推理 | 无GPU环境也能实时运行 |
| 多任务统一 | 检测/跟踪/分割/姿态估计 | 支持复杂工序识别场景 |

#### MediaPipe Hands手势识别优势

| 特性 | 描述 | 业务价值 |
|------|------|----------|
| 21关键点检测 | 精确检测手部21个关键点 | 高精度手势识别 |
| 轻量化设计 | 专为移动端/边缘设备优化 | CPU实时运行，无需GPU |
| 跨平台支持 | 支持Windows/Linux/Mac | 部署灵活 |
| 自定义手势 | 支持自定义手势分类 | 适应不同SOP需求 |

  "code": 200,

      {
        "class": "pick_tool",
        "confidence": 0.95,
        "bbox": [100, 100, 200, 200]

    ],
    "process_step": "step_1",
    "anomalies": []
  }
}

## 7. 约束条件

### 7.1 技术约束

| 约束 | 描述 |
|------|------|
| 深度学习框架 | 必须使用PyTorch + Ultralytics YOLO26 |
| 手势识别 | 必须使用MediaPipe Hands |
| 检测架构 | 采用YOLO26 + MediaPipe联合检测方案 |
| 后端框架 | 必须使用FastAPI |
| 前端框架 | 推荐使用Vue 3 |

| 约束 | 描述 |

| 可靠性 | 系统故障不得影响正常生产 |

| 资源 | 最低配置 | 推荐配置 |
