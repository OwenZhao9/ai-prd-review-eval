# v3 漏判与误判

## Z029  标准：['R3']  预测：['R1', 'R3']
> 衣橱支持穿戴/卸下；本期同一时刻最多穿戴一件，换装同步总览。徽章点击查看获得原因及时间。
- 误判 R1：「穿戴/卸下」斜杠写法没有说明是两种操作都要支持，还是任选其一。

## Z037  标准：无问题  预测：['R3']
> Pinterest 认证: 支持用户通过 OAuth 或 API Key 进行认证，以访问非公开内容或获取更高的速率限制。
- 误判 R3：「支持用户通过 OAuth 或 API Key 进行认证，以访问非公开内容或获取更高的速率限制」认证方式（OAuth 或 API Key）与认证目的（访问非公开内容或获取更高速率限制）是两个可以各自独立验收的要求，却写在了同一条需求里。

## Z053  标准：无问题  预测：['R1']
> 手动城市选择：支持真实城市和虚拟地点（家、公司）
- 误判 R1：「虚拟地点（家、公司）」「虚拟地点」的范围没有封闭，括号内只举了「家、公司」两个例子，未说明是否还有其他虚拟地点，读者无法确定完整范围。

## Z246  标准：['R1']  预测：['R1', 'R3']
> 支持多种格式文档（Word, PDF, Excel, 图片等）的导入和解析（含OCR）。
- 误判 R3：「导入和解析（含OCR）」「导入」与「解析（含OCR）」是两个可各自独立验收的要求，被并列写进同一条需求。

## Z281  标准：无问题  预测：['R2', 'R3']
> 支持数据库数据备份到指定路径
- 误判 R2：「支持」「支持」未说明备份的触发方式、频率、成功判定等可检查条件，无法验证是否满足。
- 误判 R3：「数据库数据备份到指定路径」包含「备份数据」和「指定路径」两个可独立验收的要求（备份内容与目标路径），可分别验收。

## ZD003  标准：['R4']  预测：['R3', 'R4']
> 手动城市选择：支持真实城市和虚拟地点（家、公司），虚拟地点数量上限待定。
- 误判 R3：「支持真实城市和虚拟地点（家、公司）」「支持真实城市」和「支持虚拟地点」是两个可各自独立验收的要求，被并列在同一条需求中。
