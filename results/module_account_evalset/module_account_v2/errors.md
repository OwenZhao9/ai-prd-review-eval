# module_account_v2 漏判与误判

## AD05  标准：无问题  预测：['A4']
> ### 3.3 PERM 权限管理

- **PERM-1 用户管理**：系统用户的增删改查与角色分配，支持查看用户的第三方链接、令牌、操作日志。
- **PERM-2 角色管理**：角色的增删改查与菜单权限分配，支持按菜单分配 Action 级权限（查看/新增/编辑/删除/导出）。
- **PERM-3 菜单管理**：无限级菜单树维护，每个菜单项可绑定 URL、图标、权限位，菜单树按用户权限动态生成。
- **PERM-4 部门管理**：组织架构的树形 CRUD 管理，支持用户归属部门。
- **PERM-5 多租户**：租户间数据隔离，租户管理员可管理本租户用户。
- **PERM-6 数据权限**：通过 `DataPermissionAttribute` 声明行级数据过滤规则，不同角色/用户看到不同数据行。
- **PERM-7 委托代理**：用户间权限委托，支持设置委托有效期。
- **PERM-8 访问规则**：基于 IP 白名单/黑名单的访问控制，支持按 Area/Controller/Action 配置。
- **PERM-9 安全防御**：内置威胁检测（扫描器/注入/蜜罐/协议异常）、持久化自动封禁（阶梯时长、可手动解封）与安全事件审计，默认自动模式（连续攻击自动封禁、大范围攻击临时拦截并自动回落），可配置或自动学习可信代理防伪造；详见 [安全防御](PERM-安全防御.md)。
- 误判 A4：「PERM-1 用户管理：系统用户的增删改查与角色分配，支持查看用户的第三方链接、令牌、操作日志；PERM-2 角色管理：角色的增删改查与菜单权限分配」段落描述了管理员对用户和角色进行新增、删除、修改、角色分配、权限分配等操作，但只提到可以查看操作日志，没有要求记录这些管理操作。

## AD08  标准：['A1']  预测：['A1', 'A3']
> #### 2.1.1 注册/登录功能
**优先级**: P0 (最高)

**功能描述**:
- 邮箱/手机号注册
- 邮箱/手机号登录
- 第三方登录（微信/Google/Apple，可选）
- 密码找回功能

**验收标准**:
- [ ] 用户可以成功注册账号
- [ ] 用户可以使用邮箱/手机号登录
- [ ] 密码加密存储
- [ ] 登录状态持久化（7天免登录）
- [ ] 支持密码找回流程

**技术实现**:
- 使用 Supabase Authentication 或 Firebase Auth
- JWT Token 管理用户会话
- 密码使用 bcrypt 加密
- 误判 A3：「「登录状态持久化（7天免登录）」」段落描述了登录态保持方式，但未写明登录状态在多长时间后或什么条件下失效、需要重新登录。

## AD12  标准：['A4']  预测：无问题
> ### 2\.1 权限规范

完全复用django\-vue3\-admin原生RBAC权限体系，支持**菜单权限、按钮权限、接口权限、列级别数据权限**，可针对不同角色配置各模块的新增、编辑、删除、查询、执行、导出等操作权限，支持数据范围权限管控。
