# v5 漏判与误判

## Z004  标准：['R1']  预测：无问题
> 作为用户,我希望回测在资金不足时能够自动停止,模拟真实交易场景
- 漏判：['R1']

## Z015  标准：['R1']  预测：['R1', 'R3']
> 用户故事: 作为一个对某部美剧感兴趣的用户，我希望可以告诉 LLM 这部剧的名字，以便它能告诉我关于这部剧的详细信息，如剧情简介、主要演员、评分、播出年份和季数等。
- 误判 R3：「剧情简介、主要演员、评分、播出年份和季数」剧情简介、演员、评分、年份、季数是多个可各自独立验收的信息项，并列在同一条需求里。

## Z024  标准：['R2']  预测：['R2', 'R3']
> API 和前端状态要支持一个会话至少 100 个 Artifact，列表仍保持可用。
- 误判 R3：「API 和前端状态要支持一个会话至少 100 个 Artifact，列表仍保持可用」包含两个可独立验收的要求：API 和前端状态支持至少 100 个 Artifact 的容量目标，以及列表保持可用这一独立的质量目标。

## Z033  标准：['R2']  预测：['R2', 'R3']
> 适应性学习: 系统需要具备适应性学习能力，能够根据识别结果不断优化识别算法和模板，提高识别准确性和适应性。
- 误判 R3：「优化识别算法和模板，提高识别准确性和适应性」包含「优化算法/模板」与「提高准确性和适应性」两个可各自独立验收的目标，且「准确性」和「适应性」是两种不同性质的效果。

## Z064  标准：['R1', 'R2']  预测：['R1', 'R2', 'R3']

- 误判 R3：「包括操作间隔、操作轨迹、操作习惯等」操作间隔、操作轨迹、操作习惯是三个可各自独立验收的要求，被并列写进同一条需求。

## Z075  标准：['R3']  预测：['R1', 'R3']
> 超出允许范围直接阻止输入；接近危险边界（如 Z < −0.20）时显示黄色警告但允许继续。
- 误判 R1：「如 Z < −0.20」「如」引出的示例未封闭，未说明危险边界的完整判定条件，读者无法确定除 Z < −0.20 外还有哪些条件。

## Z080  标准：['R1', 'R2']  预测：['R1', 'R2', 'R3']

- 误判 R3：「对超大文件 / 不支持预览类型应能返回明确错误或元信息」「超大文件」和「不支持预览类型」是两类不同对象，各自可独立验收，且「返回错误」与「返回元信息」是两种不同处理方式，被斜杠和「或」串在一条需求里。
